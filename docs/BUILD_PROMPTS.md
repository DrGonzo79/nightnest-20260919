# Phased build prompts

1. **Evidence intake:** Replace fixtures with versioned properties and assessments in PostgreSQL. Add photo upload, coarse/exact location separation, reviewer corrections, migrations, authorization, and contract tests.
2. **Source adapters:** Add allowlisted providers for light pollution, ephemeris, forecasts, and gear. Persist source timestamps, cache windows, circuit breakers, and explicit `SOURCE_UNAVAILABLE` / `STALE_DATA` UI states.
3. **Plan operations:** Build reviewer approval, versioned gear catalogue, placement diagram, signed audit delivery, PDF/QR artifacts, audit events, and rollback to a prior plan.
4. **Guest loop:** Generate one plain-language nightly target from structured facts, add weather fallback, accessibility variants, coarse QR analytics, opt-out, and property-level engagement reporting.
5. **Commercial pilot:** Add payment, partner attribution, refunds, affiliate disclosure, second-property purchase, unit-economics dashboard, and runbook. Only then test managed fulfillment or directory pages.
